Add a New Class

A class is the top level of the student work hierarchy. Each class contains semesters, which contain projects, which contain student submissions. This saves to data/studentwork/index.json.

Naming Convention — Class IDs

The ID Prefix becomes the start of every semester ID for this class. Keep it short, lowercase, no spaces.
Examples: at → Applied Technologies  ·  dm → Digital Media  ·  biz → Business  ·  ent → Entrepreneurship  ·  mkt → Marketing

Add a New Semester

A semester belongs to a class. This adds the semester entry to data/studentwork/index.json and creates its empty project file in data/studentwork/. Do this at the start of each new term.

Naming Convention — Semester IDs

Format: [prefix]-sem[term]-[year]
Examples: at-sem2-2026 · dm-sem1-2027 · biz-sem2-2026
The ID is auto-generated from your selections — only edit if you need something custom.

Add a New Project

A project is an assignment given to the class. Each project holds all the individual student submissions. Add a new project whenever you assign one — you can add student work to it at any time after.

Naming Convention — Project IDs & Folder Names

Format: [short-descriptive-name] — lowercase, hyphens, no spaces.
Examples: portfolio-site · brand-identity · pitch-deck · lean-canvas
The Project ID also becomes the folder name you create manually in work/[class-id]/[semester-id]/.
Example folder path: work/digital-media/dm-sem2-2026/brand-identity/

File Path Convention — Student Files

All file paths are relative to the site root (the folder containing index.html).
Format: work/[class-id]/[semester-id]/[project-id]/[student-filename]
Examples:
 Image: work/digital-media/dm-sem2-2026/brand-identity/aisha-brand-full.jpg
 Audio: work/digital-media/dm-sem2-2026/audio-design/sofia-soundscape.mp3
